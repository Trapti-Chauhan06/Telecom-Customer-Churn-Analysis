# 🏥 Healthcare Appointment No_Show Prediction

## 📌 Project Overview

This project predicts whether a patient will miss a scheduled healthcare appointment using Machine Learning. The project includes data cleaning, feature engineering, exploratory data analysis (EDA), model training, evaluation, and an interactive Power BI dashboard for visualization.

## 🎯 Objectives

- Analyze patient appointment data.
- Identify factors affecting appointment no-shows.
- Build a Machine Learning model to predict no-shows.
- Create an interactive Power BI dashboard for business insights.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Power BI

## 📂 Dataset

Healthcare Appointment No-Show Dataset (Kaggle)

Features include:
- Patient Demographics
- Appointment Details
- Medical Conditions
- SMS Reminder Status
- Attendance Status

## 📊 Exploratory Data Analysis

Performed analysis on:

- Gender Distribution
- Age Distribution
- No-Show Percentage
- SMS Reminder vs No-Show
- Diabetes vs No-Show
- Hypertension vs No-Show
- Waiting Days Analysis
- Weekday Analysis
- Correlation Heatmap

## ⚙️ Feature Engineering

Created new features such as:

- WaitingDays
- Weekday
